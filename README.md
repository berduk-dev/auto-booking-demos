# Персональные демо для шиномонтажей

Два статических примера сайта: `/12/` и `/2022/`. Формы показывают сценарий записи, но ничего не отправляют и не сохраняют. Свободные окна условные. Данные мастерских сверяются с их карточками в 2ГИС перед рабочим запуском.

Локально: `python3 -m http.server 8765`, затем открыть `http://localhost:8765/12/` или `/2022/`.

Для следующей мастерской: скопировать одну из папок, изменить объект `window.shop` в `index.html`. Общие стили и логика лежат в корне.
