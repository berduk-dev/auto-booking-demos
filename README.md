# Персональные демо для шиномонтажей

Два статических сайта: `/12/` показывает сценарий записи без отправки заявки; `/2022/` показывает услуги, телефон и адрес мастерской без формы записи. Данные мастерских сверяются с их карточками в 2ГИС перед официальным запуском.

Локально: `python3 -m http.server 8765`, затем открыть `http://localhost:8765/12/` или `/2022/`.

`/12/` использует общие `style.css` и `app.js` в корне. У `/2022/` собственные разметка и стили. Перед созданием следующей страницы проверьте данные мастерской в 2ГИС и замените контакты, услуги и фото в выбранном шаблоне.
